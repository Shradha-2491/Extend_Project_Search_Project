What this means
----------------
- No "application-debuggable" line means the release manifest does NOT set
  android:debuggable="true" -- matches app/build.gradle.kts's release
  block (isDebuggable = false). A debuggable release build would let anyone
  attach a debugger / read process memory on a non-rooted device; this APK
  does not have that exposure.
- allowBackup=0x0 (false) confirms Android's auto-backup/adb backup cannot
  export this app's private storage (which holds the EncryptedSharedPreferences
  file backing TokenStore) to a PC or the user's Google account. This closes
  off a way the encrypted-at-rest tokens' storage location could otherwise
  be exfiltrated, independent of the encryption itself -- see
  local_storage_check.txt for the encryption evidence.
